# R and RStudio Installation Instructions

Before the course, you **must install both R and RStudio** on your computer.

Please follow the installation instructions provided in this directory, selecting the appropriate document for your operating system (**Windows, macOS, or Linux**).

If you have any questions or encounter any problems during the installation, please contact us at [**infogutbioinfo@gmail.com**](mailto:infogutbioinfo@gmail.com) **before the course** so we can help you resolve them.

> ⚠️ **Important:** Please make sure everything is correctly installed and working beforehand, as you will need R and RStudio to complete the practical activities.
