# Training data

`acids.csv` contains targeted HPLC measurements of six organic acids for six samples from an in-vitro colon-model experiment.

The teaching subset contains three conditions with two replicates each:

- `Control_R1` and `Control_R2`
- `A_R1` and `A_R2`
- `B_R1` and `B_R2`

The dataset supports introductory demonstrations of data structure, wide-to-long reshaping and exploratory visualisation. With only two replicates per condition, observed differences should not be presented as statistically established treatment effects.
